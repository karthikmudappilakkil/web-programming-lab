Experiment 6 - Dynamic Product Catalogue

Aim:
To display products and filter them by name and category without reloading the page.

Basic algorithm:
1. Store product names, prices and categories in an array of objects.
2. Read the search text and selected category.
3. Loop through the products and keep matching products.
4. Display the matching products, or show a message if none match.
5. Run the filter again when the search text or category changes.

Important JavaScript concepts:
Arrays, objects, for loops, if statements, functions, events and DOM manipulation.

How to execute:
Open index.html directly in a web browser. Type a product name or select a category.

Expected output:
Eight sample products are shown. Search and category filters update the list, and a
message appears when there are no matching products.
