Experiment 10 - Online Quiz Application

Aim:
To create a multiple-choice quiz and calculate the user's score.

Basic algorithm:
1. Store each question, its four options and the correct option number in an array.
2. Loop through the array and display each question with radio-button options.
3. When the quiz is submitted, check the selected answer for each question.
4. Count the correct answers and calculate the incorrect answers.
5. Display the correct count, incorrect count and final score.

Important JavaScript concepts:
Arrays, objects, nested loops, if statements, functions, form events and DOM manipulation.

How to execute:
Open index.html directly in a web browser. Select answers and click Submit Quiz.

Expected output:
Five questions with four options each are displayed. After submission, the number of
correct and incorrect answers and the score out of five are shown.
