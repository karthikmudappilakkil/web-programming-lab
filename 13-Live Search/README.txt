Experiment 13 - Live Search

Aim:
To load data with Fetch and update matching search results while the user types.

Basic algorithm:
1. Fetch a small list of sample user records from JSONPlaceholder.
2. Store each user's name, city and company in an array.
3. Listen for changes in the search input.
4. Loop through the array and compare the search text with each field.
5. Display matching records immediately, without reloading the page.

Important JavaScript concepts:
Fetch API, async/await, arrays, objects, loops, if statements, events and DOM manipulation.

How to execute:
Open index.html in a browser with an internet connection. No API key is needed.

Expected output:
Sample people and their cities/companies appear. Search results update as text is
typed without reloading the page.
