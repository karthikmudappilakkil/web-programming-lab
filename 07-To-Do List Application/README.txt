Experiment 7 - To-Do List Application

Aim:
To add tasks, mark them completed and delete them using a dynamic task list.

Basic algorithm:
1. Keep task text and completion status in an array of objects.
2. Read a task from the input when the form is submitted.
3. Add a non-empty task to the array and redraw the list.
4. Change a task's completion status when Complete or Undo is clicked.
5. Remove a task from the array when Delete is clicked.

Important JavaScript concepts:
Arrays, objects, functions, form events, if-else statements, loops and DOM manipulation.

How to execute:
Open index.html directly in a web browser. Add tasks and use the task buttons.

Expected output:
Tasks appear below the input. They can be marked completed or deleted. Tasks are
temporary and are cleared when the page is closed or refreshed.
