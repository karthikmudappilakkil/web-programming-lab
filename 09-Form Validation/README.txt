Experiment 9 - Registration and Login Form Validation

Aim:
To validate registration and login form values in the browser using JavaScript.

Basic algorithm:
1. Read the values entered in the form.
2. Check that every required field is filled.
3. Check that the email follows a basic email format.
4. For registration, check password length and matching confirmation.
5. Display an error or success message beside the form.
6. Apply required-field, email and password-length checks to login as well.

Important JavaScript concepts:
Functions, variables, if-else statements, string length, regular expressions, form events
and DOM manipulation.

How to execute:
Open index.html directly in a web browser and try both forms.

Expected output:
Invalid or missing values show an error message. Valid values show a success message.
These forms only validate data in the browser; they do not create or check accounts.
