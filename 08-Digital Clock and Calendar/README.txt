Experiment 8 - Digital Clock and Calendar

Aim:
To display a live digital clock, today's date and a monthly calendar.

Basic algorithm:
1. Create a Date object for the current date and time.
2. Display the time and today's date using Date methods.
3. Use setInterval() to update the clock every second.
4. Find the first weekday and number of days in the current month.
5. Display the dates in calendar cells and highlight today's date.

Important JavaScript concepts:
Date methods, variables, functions, loops, if statements, setInterval() and DOM manipulation.

How to execute:
Open index.html directly in a web browser.

Expected output:
The current time updates every second. The current date and day and a monthly calendar
are displayed, with today's date highlighted.
